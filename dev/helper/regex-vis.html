💡 正则测试与替换说明：

• 测试提取：在大段文本中查找并提取所有符合规则的内容（如抓取文章中的所有 Email）。输入原文后点击「执行测试」即可。

• 批量替换：将匹配到的内容批量替换为指定文本（如将文章中的手机号替换为 ***）。输入替换内容后点击「执行替换」即可。

以下为您整理了正则表达式中最常用、最核心的元字符与语法速查表：
常用字符类简写
  • \d : 匹配任意数字，等价于 [0-9]
  • \D : 匹配任意非数字字符，等价于 [^0-9]
  • \w : 匹配字母、数字、下划线，等价于 [a-zA-Z0-9_]
  • \W : 匹配任意非单词字符
  • \s : 匹配任意空白字符（空格、Tab、换行符）
  • \S : 匹配任意非空白字符（所有可见文本字符）
  • . : 匹配除换行符之外的任意单个字符
量词与边界锚点
  • * : 匹配前面的子表达式零次或多次（如 \d*）
  • + : 匹配前面的子表达式一次或多次（如 \d+，至少1个）
  • ? : 匹配零次或一次，或用于非贪婪匹配
  • {n,m} : 匹配前面的子表达式至少 n 次，至多 m 次
  • ^ : 匹配输入字符串的开始位置（如 ^\d 以数字开头）
  • $ : 匹配输入字符串的结束位置（如 \d$ 以数字结尾）
